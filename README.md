# 🧺 주말 어디 가지?

주말마다 아이와 어디 갈지 고민하는 부모를 위한 나들이 추천 페이지입니다.
**날씨, 예산, 거리, 그날 영업 여부**를 점수로 매겨 장소끼리 나란히 비교해 줍니다.

> 현재 장소 정보는 **샘플**입니다. 다음 단계에서 한국관광공사 TourAPI로 바꿔 실제 운영 중인 곳만 보여줄 예정입니다.

## 기능
- 출발지(지역 선택 또는 내 위치)와 가족 구성(어른·영유아·유아·초등) 설정
- 7일 날씨·미세먼지 예보 (장소마다 따로 조회), 주말 자동 선택
- 장소별 점수: 날씨 적합도 / 예상 비용(입장료+주차+기름값) / 이동 시간 / 영업 여부
- 우선순위(균형·날씨·예산·거리)에 따라 종합 점수 순위
- 최대 3곳 나란히 비교 (항목별 가장 좋은 곳에 👑 표시)
- 그날 쉬는 곳·예산 초과·날씨 안 맞는 곳은 이유와 함께 따로 표시
- 🎲 "그냥 골라줘" 버튼

## 구조
```
index.html          화면
style.css           디자인
app.js              날씨 조회, 점수 계산, 비교
data/places.json    장소 데이터 (지금은 샘플)
```

날씨는 [Open-Meteo](https://open-meteo.com)(무료, 키 불필요)를 브라우저에서 바로 불러옵니다.

## 로컬 실행
```bash
python -m http.server 8765
```

## 실제 장소 데이터 (TourAPI)
`scripts/fetch_places.py`가 한국관광공사 TourAPI에서 서울·인천·경기의 관광지, 문화시설, 레포츠, 축제를 받아
아이와 갈 만한 곳만 골라 `data/places.json`을 만듭니다.

- 목록에서 사라진 곳(폐업·삭제)은 자동으로 빠집니다.
- 쉬는 날("매주 월요일", "1월 1일"), 운영 기간("7~8월"), 이용시간, 요금을 글에서 읽어 숫자로 바꿉니다.
- 수정일이 바뀐 곳만 상세 정보를 다시 받아 하루 호출 한도(개발계정 1,000회)를 넘지 않게 합니다.
- `.github/workflows/update-places.yml`이 매일 새벽 3시에 자동 실행하고, 바뀐 내용이 있으면 커밋합니다.

```bash
# 키 확인 (응답 형식 출력)
TOUR_API_KEY=발급키 python scripts/fetch_places.py --check
# 파싱 테스트 (키 불필요)
python scripts/test_fetch_places.py
```

GitHub 저장소 Settings → Secrets and variables → Actions에 `TOUR_API_KEY`를 등록하세요.

## 우리 가족 리뷰 · 요청 게시판 (구글 폼 + 구글 시트)
외부 리뷰 API가 없어서, 리뷰와 요청은 구글 폼으로 받고 구글 시트를 사이트가 읽어옵니다.
설정은 [reviews-config.js](reviews-config.js)에 적습니다. 비워 두면 해당 기능은 꺼집니다.

1. 구글 폼 2개를 만들고 응답을 같은 시트에 연결합니다 (폼마다 시트 탭이 하나씩 생깁니다).
   - 리뷰 폼 질문: `장소 ID`, `장소 이름`, `별점`(1~5), `한 줄 평`, `아이 나이`
   - 요청 폼 질문: `요청 내용`, `닉네임`(선택)
   - 요청 시트 탭에는 `상태`, `답변` 열을 직접 추가해 운영자가 채웁니다. 상태는 `접수`/`진행중`/`완료`/`보류`.
2. 시트 공유를 **링크가 있는 모든 사용자 – 뷰어**로 바꿉니다.
3. 각 탭의 CSV 주소를 설정에 넣습니다. `gid`는 탭을 열었을 때 주소창의 `gid=` 값입니다.
   `https://docs.google.com/spreadsheets/d/<시트ID>/gviz/tq?tqx=out:csv&gid=<탭gid>`
4. 리뷰 폼은 "미리 채워진 링크"를 만들어 `장소 ID`, `장소 이름` 항목의 `entry.숫자`를 설정에 넣습니다.
   카드의 "리뷰 남기기"를 누르면 그 장소가 미리 채워진 폼이 열립니다.

열 이름은 키워드로 찾으므로 질문 제목이 조금 달라도 됩니다 (예: "별점" 포함, "한 줄 평"·"후기" 포함).
형식 예시는 [data/reviews.sample.csv](data/reviews.sample.csv), [data/requests.sample.csv](data/requests.sample.csv).
